Looper combos

Hold both Mode buttons, then press a key on the side whose looper you want to control.

CAudio: record
C#Audio: play
DAudio: overdub
D#Audio: bypass (keeps the loop)
Hold EAudio: clear the loop (1 s)
FAudio: speed down one step (4th, 5th, octave); hold ½ s: octave down
F#Audio: speed 1×; hold ½ s: cycle varispeed → pitch (length kept) → stretch (pitch kept)
GAudio: speed up one step (4th, 5th, octave); hold ½ s: octave up
G#Audio: loop level −
ANotes: record → close and play → stop → play
Hold ANotes: clear the sequence (1 s)
A#Audio: loop level +
BAudio: reverse on/off

Outside the looper layer: hold the left Mode button and press a key to set that side's sequencer threshold; hold the right Mode button and press a left key for pre clip gain or a right key for post clip gain (C lowest, B highest).

After A starts a note recording, release the Mode buttons and play; press both Mode buttons + A again to close the loop. Notes follow the current octave and mode (not in Cave mode).

View over USB (Web Serial, Chrome or Edge). The only controls are each side's Pan, SOS and speed steps: Pan changes the running state (save it from the configuration page or by holding both Mode buttons for 3 s); SOS and speed are not saved (SOS returns to 80%, speed to 1× at power-on). Close the page before using the Arduino serial monitor or the web flasher. Requires firmware v4.30-duallooper.5 or later; Pan and SOS need v4.30-duallooper.6 or later, the speed steps v4.30-duallooper.7 or later.
